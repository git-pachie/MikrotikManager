# 01 Foundation

### 01.01 (187 characters)

Create Netora MikroTik Manager V1 using ASP.NET Core MVC, ASP.NET Core Web API, SQL Server, EF Core, Bootstrap 5, and Clean Architecture. Keep Web UI and Backend API in separate projects.

### 01.02 (162 characters)

Create Domain, Application, Infrastructure, WebApi, and WebUI projects. Keep business rules in Application. WebUI must not directly access SQL Server or MikroTik.

### 01.03 (191 characters)

Use dependency injection, async operations, DTO validation, structured logging, centralized error handling, and consistent API responses. Design business operations for future mobile clients.

### 01.04 (146 characters)

Store credentials and secrets securely using environment-specific configuration. Never commit production passwords, connection strings, or tokens.
