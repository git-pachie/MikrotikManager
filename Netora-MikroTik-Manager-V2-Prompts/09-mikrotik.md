# 09 Mikrotik

### 09.01 (113 characters)

Implement RouterOS 7 REST API integration over HTTPS with one MikroTik on the same LAN as the application server.

### 09.02 (157 characters)

Secure MikroTik host, port, and dedicated service account credentials. Restrict router API access to the app server and never expose credentials to browsers.

### 09.03 (139 characters)

Check MikroTik status and configuration only when opening or refreshing a customer profile. Do not schedule periodic synchronization in V1.

### 09.04 (142 characters)

Compare SQL expectations with actual MikroTik PPPoE settings and display Configuration Mismatch. Do not automatically overwrite either system.
